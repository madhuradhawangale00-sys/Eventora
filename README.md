# 🎉 Eventora – Full Stack MERN Event Booking Platform

Eventora is a **full-stack Event Booking and Management Platform** built using the **MERN Stack (MongoDB, Express.js, React.js, Node.js)**. It allows users to explore events, book tickets securely with email OTP verification, and track booking status, while providing administrators with a powerful dashboard to manage events, bookings, and platform analytics.

This project demonstrates real-world concepts such as **JWT Authentication, Role-Based Access Control, OTP Verification, REST APIs, MongoDB Integration, and Admin Analytics**.

---

## 🚀 Features

### 👤 User Features

* User Registration & Login
* Secure JWT Authentication
* Email OTP Verification
* Browse Upcoming Events
* View Event Details
* Book Event Tickets
* Track Booking Status
* View Booking History
* Responsive User Dashboard

### 🛠️ Admin Features

* Secure Admin Login
* Create New Events
* Edit Existing Events
* Delete Events
* Manage Booking Requests
* Approve or Reject Bookings
* Confirm Payments
* Dashboard Analytics

  * Total Events
  * Confirmed Bookings
  * Pending Requests

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/madhuradhawangale00-sys/Eventora.git
```

```bash
cd eventora
```

---

### Install Backend Dependencies

```bash
cd server
npm install
```

---

### Install Frontend Dependencies

```bash
cd ../client
npm install
```





## ▶️ Run the Project

### Start Backend

```bash
cd server
npm run dev
```

### Start Frontend

```bash
cd client
npm run dev
```

Open your browser and visit:

```text
http://localhost:5173
```
